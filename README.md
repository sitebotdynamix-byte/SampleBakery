# Sample Bakery (concept site)
Fictional bakery in Laramie, WY. Plain HTML, CSS and JS. No build step.

- Open: double-click `index.html` (photos need internet).
- Host: upload the folder to any static host.
- Change hours and holidays: edit `WEEK`, `FIXED`, `YEAR` at the top of `script.js`, then update the hours table and holiday note in `index.html`.
- Change details: search `index.html` for `555-0142`, `samplebakery.example`, `214 Example Street`, and the reviews.
- Photos: see `IMAGE-LOG.md`. All details are fictional. Sample site by Korbin Boal.
